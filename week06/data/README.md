# 当前两个场景的初始条件

`scene_initial_conditions.json` 由 `run_experiments.py` 生成，逐实验保存行人数、车数、初始位置、初速度与目标，便于独立核查。

场景一为4个行人和1辆车；场景二为N=1…6六组，每组N个行人和N辆车，共2N个主体。圆周半径固定10米，车辆在右半圆均匀分布，配对行人在对径点，各自目标为起点负值。单位为米、秒，均为合成初态，无原始帧率或厘米单位假设。

原先 64 人数据副本与旧数据说明保留于 `archive/initial_64people_version/data/`，当前实验不读取该数据，也不调用其他周代码。
