# 共同动力学、几何与四种交互模型

这是一组自行实现的教学机制模型和消融对照；不把它们冒充标准 ORCA 或某篇论文的完整复现。源码为 `models.py`。人和车每一步调用同一 `acceleration` 和 `simulate`；没有根据主体类别切换另一套加速度模型。

当前场景一为 4 个行人和 1 辆车；场景二包含 N=1…6 六组，每组 N 个行人和 N 辆车，从圆周配对的对径位置出发。所有主体独立更新，交互求和遍历同场景其他全部主体，包括车车、人车和人际配对。

## 1. 全体主体共用的运动公式

记位置为 r，速度为 v，目标为 g，目标方向 e=(g−r)/‖g−r‖。

```text
v_desired = v0 · min(‖g−r‖/0.8 m, 1) · e
a_drive = (v_desired − v) / tau
a = limit_norm(P · [a_drive + a_current + a_predict + a_side + a_wall], a_max)
v_new = project_allowed_velocity(limit_norm(v + dt·a, 1.25·v0))
r_new = r + dt·v_new
```

P 是运动自由度参数：行人为单位矩阵；汽车初始航向 h=(g−r_initial)/‖g−r_initial‖，P=h·h转置。汽车速度为 max(v·h,0)h，不倒车。该投影沿每辆车各自的航向，不能把多车都沿全局 x 轴处理。它是可行域约束，不是给汽车另写制动模型。窄路车辆 h=(−1,0) 时自然退化为沿 x 轴运动。

所有主体同时读取旧状态、同时更新，不按顺序让先更新者占优势。到达目标 0.25 m 内后保持位置、速度归零；已到达主体仍参与其他主体的交互。这个到达吸收规则是模型假设。

## 2. 几何净空

行人为半径 R=0.25 m 的圆；汽车为沿初始航向固定朝向、半长 2.2 m、半宽 0.9 m 的有向矩形。圆—圆净空为 ‖r_i−r_j‖−R_i−R_j。

圆—矩形：先将圆心相对车中心的向量旋转到车辆局部坐标 (车长方向、左侧方向)，局部相对坐标为 d，矩形半尺寸为 h，q=|d|−h，矩形有符号距离：

```text
SDF_box(d) = ‖max(q,0)‖ + min(max(q_x,q_y),0)
gap = SDF_box(d) − R_circle
```

normal 为该有符号距离相对位置的外向单位法向；矩形内部使用最近面法向，完全相同中心的圆对法向设零。预测位置进入矩形内部时，采用当前分离法向，避免对称情况下凭空指定侧移方向。

车—车使用分离轴定理（SAT）。候选轴 u 为两车的车长和车宽方向共四个单位向量；第 i 车在 u 上的半投影长度 s_i(u)=L_i/2·|h_i·u|+W_i/2·|left_i·u|。

```text
margin(u) = |(r_i−r_j)·u| − s_i(u) − s_j(u)
gap_SAT = max_u margin(u)
```

gap_SAT>0 表示两矩形至少沿一个轴分离，<0 表示实体重叠。它是有符号分离裕度，正值不是精确欧氏最近距离。排斥法向使用取得最大裕度的轴，并按中心差取外向方向；多个轴同为最大时对活动法向取平均再归一化，避免结果依赖主体编号或旋转舍入。完全重合且无方向时法向为零，重叠仍被记录。预测两车中心相同则使用当前分离法向。

三类分别保存：min_car_gap 是所有人车最小净空，min_ped_gap 是人际最小净空，min_vehicle_gap 是车车最小SAT裕度。min_gap 是全部三类量的最小值，用于符号检测；不把它声称为统一的精确欧氏距离。

负净空表示几何重叠。记录阈值为 −1e−6 m，避免舍入噪声。检测发生于内部积分时刻，不是解析连续碰撞时间；0.01 s 重跑用于检查步长敏感性，不构成连续时间安全证明。

## 3. 四种模型的区别

GOAL 只保留驱动和道路边界作用；DIST 再增加当前净空排斥：

```text
a_current_i = sum_j A · exp(−max(gap_ij, −0.3 m)/B) · normal_ij
A = 5 m/s², B = 0.45 m
```

负净空的指数输入在 −0.3 m 截断，避免数值发散；这不是把身体重叠修复为合法位置。

PRED 再增加短时预测项。相对位置 d=r_i−r_j、相对速度 u=v_i−v_j：

```text
t_star = clip(−d·u / max(‖u‖², epsilon), 0, H), H=2 s
d_future = d + t_star·u
gap_future, normal_future = surface_geometry(d_future)
risk_ij = exp(−max(gap_future,0)/B) · I(d·u<−epsilon) · I(t_star>0.02 s)
a_predict_i = sum_j A · risk_ij / (1+t_star/1 s) · normal_future_ij
```

t_star 是匀速外推下的**中心最近接近时刻**，不是精确身体接触时间；即使对矩形也只在该时刻检查几何净空。未求整个时间区间的最小圆—矩形净空，也没有安全保证。

SIDE 在 PRED 上增加共同的右侧偏好项：

```text
e_right = (e_y, −e_x)
urgency_i = 1 − product_j(1 − clip(risk_ij,0,1))
a_side_i = K · urgency_i · e_right, K=3.5 m/s²
```

聚合紧迫度位于 [0,1]，避免人数越多侧向力就无限增大。右侧偏好是人为声明的模型假设，不来自此次数据的行为统计。它也为汽车计算，再经过同样的自由度投影；因此汽车不会横移。

## 4. 边界与物理能力

窄路纵向两端不设墙；四名行人的目标分别为 x=30、32、34、36 m，汽车目标为 x=4 m。横向边界 y=±W/2：

```text
extent_i = max(radius_i, box_half_width_i)
g_lower = y_i + W/2 − extent_i
g_upper = W/2 − y_i − extent_i
a_wall_y = A_wall [exp(−max(g_lower,−0.3)/B_wall)
                 − exp(−max(g_upper,−0.3)/B_wall)]
A_wall=12 m/s², B_wall=0.15 m
```

圆周六组均不设边界力：圆只表示起点布局。第N组车辆角度 theta_k=(k−(N−1)/2)pi/N，行人在其对径，各自目标为起点负值，所有2N个起点均匀分布。窄路的边界作用是软力，可能越界；位置从不强制裁剪到道路内。驱动、交互、边界之和受 a_max 限制，强排斥也无法无限制地改变速度。

固定汽车中心线时，每侧剩余宽度为 W/2−0.9 m；行人需要完整直径 0.5 m，因此 W≥2.8 m 才有无重叠并排位置，严格正间隙需要 W>2.8 m。几何可行不意味着动力学一定能通过。

## 5. 评价及解释边界

成功=全体到达且全程没有几何重叠和越界。失败后继续积分仅用于诊断，绝不将后续到达等同安全成功。细步长重叠时长表示“至少存在一对重叠”的累计时长，不是独立碰撞次数。等待时间不包括主体到达后的停留。

当前实验均为合成机制实验，不使用原64人轨迹评价人车，因此没有ADE/FDE。分开报告三类净空/分离裕度、行人到达比例和车辆到达比例。仅一车时车车量不适用、仅一人时人际量不适用。圆周的配对错身时间要求每一个行人沿原直径方向完全越过对应车尾；不替代与其他主体的安全检查。模型没有经过真实人车数据的标定或验证。
