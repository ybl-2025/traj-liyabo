# 模型公式、符号、量纲与复现范围

当前使用固定21段训练、13段测试，每段30秒。理想实验使用默认参数，真实实验同时比较默认参数与仅用训练片段标定的参数。

本项目复现 OVM、FVDM、IDM 的核心连续时间跟驰动力学，使用统一 SI 仿真框架。不是原论文全部仿真图的逐图复制。下文明确列出公式的教学量纲化和常用变体，默认值是本项目实验设置，不宣称是三篇原文的统一标定结果。

## 1. 统一符号与车辆几何

| 符号 / 代码 | 含义 | 单位 |
|---|---|---|
| `x`, `leader_x` | 后车、前车的纵向前端位置 | m |
| `v`, `leader_v` | 后车、前车速度，沿道路前进为正 | m/s |
| `leader_length` | 前车车长 | m |
| `s = leader_x - x - leader_length` | 保险杠之间的净间距 | m |
| `Δv = leader_v - v` | 前车减后车速度，用于 FVDM | m/s |
| `c = v - leader_v = -Δv` | 接近速度，用于 IDM；正值表示正在追近 | m/s |
| `dv/dt` | 模型输出的纵向加速度 | m/s² |

NGSIM `local_y_m` 按车辆前端位置处理。公式使用前车车长，不减后车车长，也不把车头间距直接当成净间距。不同论文的下标顺序和速度差定义可能相反，代码统一后再写方程。

所有模型同时满足 `dx/dt = v`。本项目只有一辆外生前车与一辆模拟后车，未实现换道或车队环路。

## 2. OVM：最优速度模型

\[
\dot v=\kappa[V(s)-v].
\]

`κ` 是速度调整灵敏度，单位 s⁻¹；`1/κ` 是速度松弛时间尺度，不应直接称为显式驾驶员反应延迟。方程没有 `v(t-τ)` 一类延迟变量。

采用归一化且量纲明确的双曲正切目标速度：

\[
V(s)=v_0\frac{\tanh((s-h)/\ell)+\tanh(h/\ell)}{1+\tanh(h/\ell)}.
\]

`v0` 是渐近自由速度（m/s）；`h` 是曲线拐点间距（m）；`ell` 是过渡尺度（m），使 `tanh` 的输入无量纲。该曲线满足 `V(0)=0`、`V(+∞)=v0`。`h` 不是静止安全间距，也不是时距。

Bando 原文包含无量纲形式。本项目保留间距反馈及 tanh 函数结构，增加显式长度尺度并归一化到给定自由速度。使用净间距等于将车头间距表达中的车长平移吸收到曲线参数。不能把这里的 `h`、`ell` 数值直接与原文无量纲参数逐项比较。

## 3. FVDM：全速度差模型

\[
\dot v=\kappa[V(s)-v]+\lambda(v_{\rm leader}-v).
\]

`λ` 的单位是 s⁻¹。前车更快时该项为正，前车更慢时为负，两个方向均生效；不能误写成仅在追近时生效的单侧项。若 `λ=0`，模型严格退化为本项目的 OVM。

Jiang 等原文式(7)给出全速度差动力学，原文也采用另一组 tanh 最优速度函数及参数。本项目让 OVM 和 FVDM 共用上面的 `V(s)`，默认实验也共用 `κ`，以明确展示新增速度差信息的作用；这不是原文参数表的原样抄用。

## 4. IDM：智能驾驶员模型

\[
\dot v=a\left[1-\left(\frac v{v_0}\right)^\delta-\left(\frac{s^*}{s}\right)^2\right],
\qquad
s^*=s_0+\max\left(0,vT+\frac{v(v-v_{\rm leader})}{2\sqrt{ab}}\right).
\]

| 参数 | 含义 | 单位 |
|---|---|---|
| `v0` | 期望自由速度 | m/s |
| `a` | 自由加速尺度 | m/s² |
| `b` | 舒适减速度尺度（正数） | m/s² |
| `T` | 期望净时距 | s |
| `s0` | 静止期望净间距 | m |
| `delta` | 自由加速指数 | 无量纲 |

动态项 `v(v-v_leader)/(2√ab)` 的单位是 m。当后车更快时，它增大期望间距；分母中的 `a,b` 都取正值，实际制动加速度由方程产生负号。`b` 不是加速度硬下限，IDM可产生比 `-b` 更强的减速度。

2000年原文的期望间距还允许 `s1√(v/v0)` 项，文中主要实验设 `s1=0`，本项目同样不启用该项。本项目使用作者后续介绍中常用的 `max(0, …)` 形式，避免当前车明显更快时动态部分令期望间距降至负数；这是明确的实现变体，不声称与原文未截断形式在所有状态完全等价。

## 5. 默认参数与标定范围

| 模型 | 本项目默认参数 |
|---|---|
| OVM | `v0=30 m/s, kappa=0.6 s^-1, h=25 m, ell=10 m` |
| FVDM | 与 OVM 相同，另有 `lam=0.6 s^-1` |
| IDM | `v0=30 m/s, a=1.2 m/s², b=2 m/s², T=1.5 s, s0=2 m, delta=4` |

三者默认自由速度均为30 m/s，不代表各自平衡间距完全相同。理想实验保持这组参数，真实跟驰在此之外增加训练集标定。

| 参数 | 标定范围 |
|---|---|
| `v0` | 15–40 m/s（所有模型） |
| `kappa` | 0.1–2 s⁻¹ |
| `h` | 5–50 m |
| `ell` | 2–30 m |
| `lam` | 0–2 s⁻¹ |
| `a` | 0.2–3 m/s² |
| `b` | 0.5–5 m/s² |
| `T` | 0.3–3 s |
| `s0` | 0.5–5 m |
| `delta` | 固定为4 |

范围用于限制本教学实验的搜索空间，不是文献给出的通用置信区间。每模型使用默认参数和范围中点两个确定性初值。21段训练片段共同拟合一个参数集，不对测试片段逐段拟合。

\[
J=\operatorname{mean}\left(\{(x_{sim}-x_{obs})/10\}^2,\{(v_{sim}-v_{obs})/2\}^2\right).
\]

上式将所有训练片段的非初始时间点拼接，分母分别为10 m与2 m/s。初始状态相同，因此剔除初始点。两类残差无量纲，训练优化完整30秒轨迹而非逐帧使用观测状态。失败后的剩余残差取100惩罚。优化器是有界 `scipy.optimize.least_squares`，各初值最多120次函数评估；保存收敛状态和训练目标值，按较低训练目标选参数。训练向量化版本检查子步端点，最终评估由检查连续间距极值的标量模拟器执行。

拥堵数据可能缺少接近自由速度的记录，`v0` 容易辨识不足；触及边界的参数必须结合数据分布说明，不能无条件解释成司机属性。

## 6. 数值实现与失败定义

每个0.1 s观测间隔拆成两个0.05 s内部步长。一个子步内保持后车加速度常数：

\[
v_{new}=v+\dot v\,dt,\quad
x_{new}=x+v\,dt+\tfrac12\dot v\,dt^2.
\]

若子步末速度将小于0，先求停止时刻 `τ=-v/accel`，只行驶 `vτ+0.5 accel τ²`，余下时间停留，下一步重新计算加速度。不允许倒车。该处理次数单独记录。

前车位置、速度分别按原始观测线性插值；理想场景前车位置由解析函数采样，子步内同样线性插值。这样三个模型回放同一输入，同时保留原始NGSIM位置/速度的测量差异。

每个子步内，检查端点、停止时刻以及间距二次函数的内部驻点。首次 `s≤0` 标为碰撞并二分定位时刻，接触后不继续轨迹，后续结果记NaN；不通过强制间距截断隐藏碰撞。非有限加速度或 `|accel|>1e8` 记数值失败，后一个值仅用于识别数值爆炸，绝不是车辆制动限值。没有给模型额外的碰撞避免控制器或现实车辆加速度限幅。

`|accel|>8 m/s²` 只作为强加减速诊断。更小步长的检查输出 `results/step_size_check.csv`。未发生碰撞只能说明该输入、参数和数值设置下没有接触，不能保证所有初态、物理限幅或现实驾驶条件安全。

3. Treiber, M., Hennecke, A., & Helbing, D. (2000). *Congested traffic states in empirical observations and microscopic simulations*. Physical Review E 62, 1805–1824. [DOI](https://doi.org/10.1103/PhysRevE.62.1805)；[作者预印本](https://arxiv.org/abs/cond-mat/0002177)。核对加速度式(6)与期望间距式(7)。
